# Хөгжлийн ажиглалт-үнэлгээний систем

Цэцэрлэгийн багш нарт зориулсан хүүхдийн хөгжлийг Суралцахуйн 7 чиглэлээр өдөр бүр ажиглаж,
тэмдэглэл хийх, сар/улирлаар анализ хийж график харьцуулах систем.

Технологи: **Next.js (App Router) + Supabase (Auth/DB/Storage) + Vercel**.

## 1. Supabase төсөл бэлдэх

1. [supabase.com](https://supabase.com) дээр акаунт үүсгэж, шинэ project үүсгэнэ.
2. **SQL Editor** руу орж [`supabase/schema.sql`](./supabase/schema.sql) файлын агуулгыг бүхлээр нь paste хийж **Run** дарна.
   Энэ нь бүх хүснэгт, аюулгүй байдлын дүрэм (RLS), Storage bucket, автомат seed өгөгдлийг үүсгэнэ.
3. **Project Settings → API** хуудаснаас дараах хоёр утгыг авна:
   - `Project URL`
   - `anon public` key

## 2. Локал орчинд ажиллуулах

```bash
cp .env.local.example .env.local
# .env.local файлд дээрх Project URL, anon key-г тавина
npm install
npm run dev
```

http://localhost:3000 хаягаар нээгдэнэ. Эхлээд "Бүртгүүлэх" таб дээр багшийн бүртгэл үүсгэнэ.

## 3. Deploy (Vercel)

Vercel project дээр Environment Variables хэсэгт `NEXT_PUBLIC_SUPABASE_URL`,
`NEXT_PUBLIC_SUPABASE_ANON_KEY`-г нэмээд deploy хийнэ.

## Цэсний бүтэц

- **Бүлэг** — багшийн хариуцсан бүлгүүд
- **Хүүхдүүд** — хүүхэд бүрийн хувийн болон эцэг эхийн мэдээлэл
- **Ажиглалт тэмдэглэл** — 7 чиглэлээр өдөр тутмын ажиглалт, зураг/бичлэг хавсаргах (камераар шууд авах боломжтой)
- **Анализ дүгнэлт** — сар/улирлаар chart, харьцуулалт
- **Тайлан тохиргоо** — 7 чиглэлийн нэршил тохируулах, хэвлэх боломжтой тайлан үүсгэх
